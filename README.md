## 🔥 Featured Visual Mods

### 🎨 Willybach's HD Valheim 2.0 (Texture Overhaul)

**Author:** Willybach, Panoc, BadgerInt | **Source:** Nexus Mods | **Size:** 148K+ Unique Downloads [citation:2]

The most comprehensive HD texture pack for Valheim. It replaces almost all vanilla textures with detailed 2K and 4K versions while preserving the original color scheme and atmosphere [citation:1][citation:2].

**Features**:
- **Handmade Textures** — Almost zero "upscaled" textures; mostly original replacements [citation:2]
- **Multiple Variants** — Medium (4-8 GB VRAM) and Low (1K textures for weaker PCs) 
- **Required Mods** — Works best with Badger's HD Terrain, Valheim Skies, and Shading Overhaul [citation:2]

**Installation**:
1. Install **BepInEx** for Valheim.
2. Download the texture pack and extract the `.png` files.
3. Place them in `Steam\steamapps\common\Valheim\BepInEx\plugins\Custom Textures\` [citation:15].
4. Launch the game.

> ⚠️ **Warning**: Do **NOT** use the Vulkan API with this mod. Switch to DirectX to improve FPS and reduce stuttering [citation:2].

### 🌟 Valheim Visuals (Engine Tweaks)

**Author:** ivvty | **Source:** Nexus Mods | **Size:** Lightweight [citation:5]

A mod that unlocks hidden graphics settings already built into Valheim's own shaders. It does not add new assets or replace shaders—it simply turns up the values the developers left low [citation:5].

**Features**:
- **Shadow Distance** — Increased from 150m to 300m [citation:5]
- **Water Tessellation** — Increased from 4 to 16 [citation:5]
- **Screen Space Reflections** — Enabled (vanilla never enables it) [citation:5]
- **Grass Radius** — Increased from 140m to 200m [citation:5]

**Installation**:
1. Install **BepInEx** for Valheim.
2. Place the `.dll` file in the `BepInEx\plugins` folder.
3. Launch the game. Settings apply instantly.

### 🎬 Valhalla ReShade HD (Cinematic Preset)

**Author:** Community | **Source:** Nexus Mods | **Size:** Safe to use [citation:10]

A ReShade preset designed to work alongside Willybach's HD Valheim. It gives the world a warmer, more nostalgic feel with richer visuals, less dullness, and a sharper image [citation:10].

**Features**:
- **Warmer Colors** — Enhances the Viking atmosphere [citation:10]
- **Sharper Image** — Removes the "dullness" of vanilla visuals [citation:10]
- **Works with Vanilla** — Can be used without HD textures, but looks best with them [citation:10]

**Installation**:
1. Download **ReShade** from the official website.
2. Select `valheim.exe` and choose **DirectX 10/11/12**.
3. Install all effects.
4. Place the `.ini` file in your Valheim root folder.
5. Press `HOME` in-game to select the preset.

### ⚡ Ray Tracing Mod (Experimental)

**Author:** kewb | **Source:** Nexus Mods | **Size:** Public Beta [citation:13]

Adds **hardware ray tracing** to Valheim using DirectX 12. It improves shadows, reflections, ambient occlusion, and global illumination without changing the original art style [citation:13].

**Features**:
- **Ray Traced Shadows** — Sunlight and local light shadows [citation:13]
- **Ray Traced Reflections** — Water and supported surfaces [citation:13]
- **ReSTIR** — Advanced sampling for realistic lighting [citation:13]

**Requirements**:
- **DirectX 12 GPU** with hardware ray tracing support [citation:13]
- **Valheim Universal Upscaler** (mandatory) [citation:13]
- **High-end GPU** — expect a substantial frame-rate cost [citation:13]

**Installation**:
1. Install **BepInEx** and **Valheim Universal Upscaler**.
2. Extract the archive into your Valheim folder.
3. Press `F1` in-game to open settings.

> ⚠️ **Warning**: This is a **public beta**. It is extremely demanding and currently only tested on NVIDIA hardware [citation:13]. Use for screenshots, not for performance-sensitive gameplay.

## 🚀 Installation

> ⚡ **Quick & Easy — takes less than 5 minutes!**

### Step 1 Install BepInEx (Required Base)

1. Download **BepInEx** (x64) for Valheim.
2. Extract the contents into your Valheim root folder (`Steam\steamapps\common\Valheim`).
3. Launch the game once to generate the `BepInEx\plugins` folder.

### Step 2 Install Visual Mods

1. Download the mods from the buttons above.
2. Extract the `.dll` files into `BepInEx\plugins`.
3. For HD Textures, place `.png` files in `BepInEx\plugins\Custom Textures`.
4. For ReShade, install ReShade and place the `.ini` file in the root folder.

### Step 3 Launch and Configure

1. Launch Valheim.
2. Press `HOME` to configure ReShade.
3. Press `F1` to configure Ray Tracing (if installed).
4. Enjoy the upgraded visuals!

> ⚠️ **Antivirus warning?** BepInEx and ReShade are sometimes flagged as false positives. Add the folders to your exceptions list.

## ❓ FAQ

### ❓ Is this a crack or pirate version?
**No.** These are visual mods and ReShade presets. You still need to own Valheim.

### ❓ Will I get banned?
**No.** Iron Gate does not ban players for using mods. However, Valheim has **no official mod support**, so mods may break after updates [citation:7].

### ❓ Does it work with the 1.0 release?
**Yes.** The mods listed are updated for Valheim 1.0 (September 2026) [citation:1][citation:5].

### ❓ Does it work on Windows 11?
**Yes.** Fully compatible with Windows 10 and 11 (64-bit).

### ❓ Can I use these mods in co-op?
**Yes.** Visual mods are **client-side only** and do not affect other players. However, all players should have similar mods for the best experience.

### ❓ How to uninstall?
Delete the mod files from `BepInEx\plugins`. For ReShade, delete the `reshade-shaders` folder and `.ini` file. No registry changes are made.

### ❓ What if the game crashes?
- Ensure BepInEx is up to date.
- Remove recently added mods.
- Check the `Player.log` file for errors.
- HD textures may cause VRAM exhaustion on lower-end GPUs [citation:9].

### ❓ Does Ray Tracing work on AMD?
**No.** The Ray Tracing mod is currently only tested on NVIDIA hardware [citation:13].
